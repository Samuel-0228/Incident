# INSA Summer Camp Learning Resources

This repository brings together resources and practical work from my INSA Summer Camp learning activities. It covers network security, hands-on security exercises, web application security, and Bilt, a security toolkit I built for AI-assisted coding workflows.

## Areas of Study

The learning activities during the camp focused on the following areas:

- Network security: Fundamental networking concepts, traffic flow, threat models, and perimeter defense mechanisms.
- Hands-on security exercises: Practical penetration testing, service enumeration, and defensive monitoring labs.
- Web application security and PHP vulnerability research: Web application flaw analysis, OWASP security standards, parameter tampering, and PHP runtime vulnerability mechanisms.
- Security automation and AI-assisted development: Building tooling to detect and mitigate common software security weaknesses in automated and AI-driven development workflows.

These topics represent areas of active learning, study, and practical experimentation.

## Repository Contents

The documentation is organized into the following sections:

- [Network Security](network-security.md): Cisco Networking Academy coursework, network architecture principles, and perimeter defense concepts.
- [TryHackMe Exercises](tryhackme.md): Hands-on labs covering basic penetration testing, network scanning with Nmap, defensive security fundamentals, and PHP runtime vulnerability analysis.
- [Web Security and Vulnerability Research](web-security.md): Exploration of web application weaknesses, OWASP guidance, mass-assignment vulnerabilities, and CVE tracking concepts.
- [Bilt: Practical Security Tooling](bilt.md): Overview of Bilt, an npm security toolkit created to analyze and enforce security standards in AI-assisted coding projects.

## Practical Work

Bilt is an npm security toolkit designed to help evaluate security requirements and prevent vulnerability introduction in AI-assisted coding workflows. It provides deterministic static analysis, pattern matching, and data flow tracking for common application security risks, such as exposed credentials, input validation flaws, and unconstrained mass assignment.

- [Bilt Documentation](https://bilt.nogs.dev/docs#security-analysis)
- [Bilt Source Repository](https://github.com/Samuel-0228/bilt)

This repository also contains the Cyber Incident Command Center, an interactive incident investigation and digital forensics simulation environment developed to model detection, analysis, and response workflows.

## Scope

This repository documents personal learning resources, lab exercises, and practical security work. It is not intended to reproduce proprietary third-party curriculum materials, publish lab solutions or flags, or duplicate Bilt's complete source code.
