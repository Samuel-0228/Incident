# Network Security

## Overview

This section documents the study of network security completed through the Cisco Networking Academy curriculum during the INSA Summer Camp. The coursework was selected as part of the skills-focused track, with an emphasis on foundational networking models, device configuration, and network protection principles.

## Topics

Based on the verified curriculum and study notes, the core topic areas explored include:

- Network security fundamentals: Concepts of data confidentiality, integrity, and availability within local and wide area network architectures.
- Common network threats: Categories of security risks including unauthorized access, credential theft, denial of service attacks, malware propagation, and internal threat vectors (Module 1.8.1).
- Network defense concepts: Protective mechanisms and perimeter security architecture, including packet filtering, Access Control Lists (ACLs), stateful inspection firewalls, and network segmentation (Module 1.8.2).
- Security practices for networked systems: Basic switch and end-device hardening, securing remote management interfaces (SSH vs. Telnet), password policies, and network protocol fundamentals (Module 2).

This list reflects the primary areas explored during the camp rather than a full reproduction of the entire multi-module CCNA syllabus.
